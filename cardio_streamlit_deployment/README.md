# Cardiovascular Disease Prediction - Streamlit

## Files
- `app.py` - Streamlit application
- `cardio_train.csv` - dataset required by the app
- `requirements.txt` - Python packages required for deployment

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

1. Push `app.py`, `cardio_train.csv`, and `requirements.txt` to a GitHub repository.
2. Open https://share.streamlit.io/
3. Sign in with GitHub.
4. Select **Create app**.
5. Select your repository and branch (`main`).
6. Set the main file to `app.py`.
7. Deploy.

Do not upload passwords, API keys, tokens, or other secrets to GitHub.
